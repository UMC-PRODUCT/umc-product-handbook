# UMC PRODUCT Handbook

UMC PRODUCT 구성원이 담당자와 책임 범위를 찾고, 다른 팀과 협업할 때 참고하는 공통 운영 문서다.

## 담당자와 협업 방법 찾기

[담당자와 책임 범위 — Ownership Registry](ownership-registry.md)에서 현재 배정된 책임자와 역할을 확인할 수 있다.

| 궁금한 것 | 찾아볼 곳 |
|---|---|
| 이 제품이나 공통 기반은 누구와 논의하나요? | [팀별 담당자](ownership-registry.md#팀별-담당자) |

## 문서 사용 원칙

- 문서에 적힌 책임 범위와 해당 제품의 실제 제공 상태는 구분한다. 담당 영역에 포함돼 있어도 모든 기능이 출시됐다는 뜻은 아니다.
- 다른 팀의 작업·인력·기한은 관련 담당자와 합의한다. 문서를 읽거나 요청을 전달한 것만으로 업무 수락이 성립하지 않는다.
- 담당자가 다르거나 내용이 오래됐다면 [문의와 문서 관리](ownership-registry.md#문의와-문서-관리)의 경로로 정정을 요청한다.
- 공개 문서와 변경 이력에는 업무에 필요한 역할·범위·합의 결과를 남긴다. 개인 연락처·개인 사정·배치 평가와 공개되지 않은 자료는 포함하지 않는다.

문서는 Organization Operations DRI인 부총괄이 관련 담당자와 함께 관리한다.
